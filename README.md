# Ticket Manager

Ticket Manager is a mobile-first application designed to help users create, manage, and track support tickets efficiently.  
It includes:
- A REST API built with **ASP.NET Core**, **Entity Framework Core**, and **PostgreSQL**
- Native iOS and Android apps (starting with iOS)

## Features
- User authentication (JWT)
- Ticket creation, editing, and management
- Ticket assignment and filtering
- Push notifications (planned)

## Tech Stack
- **Backend:** C# (ASP.NET Core Web API, EF Core) + PostgreSQL
- **Mobile:** iOS (SwiftUI), Android (Kotlin / Jetpack Compose)
- **Cloud:** Azure App Service + Azure PostgreSQL Flexible Server
- **CI/CD:** GitHub Actions (build + test, deploy planned)
