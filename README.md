# Ticket Manager

Ticket Manager is a mobile-first application designed to help users create, manage and track tickets efficiently.  
It includes:
- A REST API built with ASP.NET Core and PostgreSQL
- Native iOS and Android apps

## Features
- User authentication
- Ticket creation and management
- Notifications (planned)

## Tech stack
- Backend: C# (ASP.NET Core Web API) + PostgreSQL
- Mobile: iOS (SwiftUI), Android (Kotlin)
- Cloud: Azure (App Service + PostgreSQL Flexible Server)
- CI/CD: GitHub Actions
