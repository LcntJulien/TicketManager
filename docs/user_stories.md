# User Stories

- As a user, I want to create a ticket so that I can track an issue.
- As a user, I want to assign a ticket so that responsibility is clear.
- As a user, I want to close a ticket so that I know it is resolved.
- As an admin, I want to view all tickets so that I can monitor the system.
- As a user, I want to log in securely so that only I can access my tickets.
